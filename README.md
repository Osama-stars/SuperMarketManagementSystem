# SuperMarketManagementSystem
This is a simple project for Super Market Management System.

In this Project, I used Winforms classes along with C# as the progamming Language to make a simple SuperMarket management System.
The Hardest Part was making the Pages resposive, so whever the user changes the size of the form, the buttons have to resize accordingly. I learned that I should always put presentages instead of fixed pixles.
I also made sure that my Project can be used in two languages: English, and Arabic. And here comes the benefit of Helpers. It includes all of the translations from English to Arabic.
I added some events, so that any user can use this program without needing to move his/her mouse much.
In conclusion, thank you for reading this. Give my project a try, and if you have an issues, do not hesitate to inform me at any time. I am still eager to add more details in the future for this project, but currently, I will leave it here.
